# Visual Language Castle — Master Table Registry

This registry separates app architecture from the still-evolving physical table catalog. New tables should be addable as structured content without redesigning the app.

## Status Values
- Confirmed — function explained by source material/user description.
- Partially Confirmed — photograph exists but some function remains unclear.
- Transcribed — cards identified but function not fully documented.
- Unknown — insufficient information.

## Known Table Notes

### Relaxation / Beginning Run-On Palette
Purpose: rapid visual scanning during the beginning relaxation portion of a run-on induction.

Contains:
- central pink verb/process field
- surrounding orange/cream nominalizations
- cause/effect strip
- descriptive frames
- +LY modifier concept
- WHAT–WHAT–HOW–WHAT–WHERE scaffold

Behavior: eyes roam back and forth across the palette like a painter selecting colors.

Status: Confirmed.
