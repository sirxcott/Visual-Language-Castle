# Visual Language Castle — Color Grammar

Color is functional metadata, not decoration. The user should gradually recognize a card's linguistic role before consciously reading it.

## Confirmed / Working Color System

### Orange — Nominalizations / Vague Concepts
Use for nominalizations, vague or hypnotic concepts, and default uncategorized conceptual material.

Examples: Comfort, Clarity, Wisdom, Relaxation, Identity, Awareness.

### Pink — Verbs / Processes
Use for actions and processes. Pink remains intentionally bright because it stands out strongly during rapid scanning.

Examples: Notice, Relax, Discover, Allow, Imagine, Become.

### Green — Linkages
Use for connective language and bridges between other components.

Examples: And, And as, Because, While, And since, Or rather.

### Red — Compliance Sets / Complete Reusable Commands
Use for completed phrases or instructions intended to be reused as whole language units.

Examples:
- Relax your eyes.
- Make yourself comfortable.
- In a moment, I'm going to ask you to relax.

A red compliance card is different from a pink single verb such as `RELAX`.

### Yellow — Provisional
Historically associated with embedded commands but not yet finalized. It may better represent noticing/attentional or less-specific suggestive language.

Do not permanently lock this category until more source material is documented.

## Blue Family
Blue currently contains three separate functions that should be visually distinguished.

### Dark Blue — Time Binds
Temporal structures and sequencing relationships.

Examples may include: while, before, after, each time, as soon as, whenever, eventually.

### Light Blue — Cause & Effect
Structured causal or sequential relationship frames.

Examples:
- As you ___, you ___.
- If you ___, then ___.
- When you ___, you'll ___.
- Because ___, so ___.
- The more ___, the more ___.

### Indigo / Blue-Violet — +LY Modifiers
Dedicated manner modifiers describing how an action or process occurs.

Examples: slowly, naturally, comfortably, gradually, quietly, easily, automatically, deeply, smoothly.

The exact shade may change later without changing the semantic category.

## Multiple Functions
A component may serve more than one linguistic function. Example: `as` may be a linkage, a time relation, or part of a cause/effect frame.

Each card therefore stores:
- primary category
- primary display color
- optional secondary functional tags

Do not duplicate identical language solely because it can serve multiple functions.
